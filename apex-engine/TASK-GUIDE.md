# Apex × 币安商业版：差距清单与任务指南

文档用途：把此前调研的差距收成可执行任务。  
对照对象：币安 Web 交易终端 + TradingView Charting Library（商业授权）+ 交易所账本/撮合。  
本仓库定位：**币安风格行情终端 + 本地模拟盘**，行情走币安公开 REST/WS，下单不进真实撮合。

状态标记

- `[x]` 本轮已落地（见文末「已交付改动」）
- `[ ]` 待做
- `[~]` 部分落地，仍差一截
- `P0 / P1 / P2` 建议优先级

---

## 0. 怎么用这份指南

1. 先跑通：`npm install && npm run dev`（默认 `0.0.0.0:8080`）。
2. 图表相关任务只动 `src/lib/market/*` 与 `src/components/terminal/*`。
3. 不要用「再加一个指标」冒充引擎/鼠标/历史渲染任务。
4. 商业授权的 TradingView Charting Library 买不到就继续自研；能买则第 2 章大量任务可替换为「接入 TV 库」。

## 4. 历史 K 实时渲染与展示

目标：拖历史 60fps、新柱只在左边长、右边活 K 继续跳、无缺根/双根。

- [x] 前置插入 + `shiftView` 钉窗口
- [x] `k.x` + `liveOpenTime`，回溯丢掉未收盘根
- [x] `updateBar` 拒绝更旧的包
- [x] 按缺口多页拉取
- [x] 左缘 whitespace 占位（`setHistoryPad`）
- [x] 子日周期 `2x～12x` 步长插空洞；周/月/3 日不插
- [x] 对比按主图时间补历史
- [x] 密视口 LOD（可见 >480 根，1s >240 根改收盘折线）
- [x] 十字 `barAtTime` 二分
- [ ] 真正「只追加左端像素、屏上柱完全不重绘」（受 LW `setData` 限制）
- [ ] 左缘按像素而不是逻辑根数触发
- [ ] 甩动距离一次补够 2～3 屏（现在最多 3×1000，但阈值仍偏逻辑格）
- [ ] REST 定时校对最近已收盘 1～2 根
- [ ] 切周期时保留旧柱直到新周期到达（现在先清空）
- [ ] 日线交易时段/周末缺口策略（加密 24h 可保持现状）
- [ ] 副图轴同步到空洞时段时主动补数，而不是等自己的 `from < 16`

验收

1. 打开 BTCUSDT 15m，向左连续拖 3 屏：旧柱从左侧长出，右侧当前 K 仍在变。
2. 加对比 ETHUSDT 再向左拖：对比线不在左缘消失。
3. 切到 1s，缩到全历史：应变折线且可拖；放大后恢复蜡烛。
4. 断网后再拖：不应把「失败」显示成「没有更早 K」。

## 8. 建议迭代顺序

只做图表、不碰真金账户时：

1. **鼠标状态机 + 画线预览 + 磁吸 + 图元可拖**（第 5 章 P0）  
   没有这一层，引擎补得再满也是「能看不能描」。
2. **画线迁 canvas**（6.5 + 5.4）  
   解决拖图时线与 K 错帧。
3. **图上委托/仓位线**（7.3）  
   终端从行情显示器变成交易终端。
4. **蜡烛样式 + tickSize + 未收盘色**（6.2 / 6.3）
5. **量图独立 pane、更细 LOD**（6.4）
6. 指标面板与模板（7.1）
7. 真盘再进第 1 章 P0（账本、钱包、撮合）

不要并行开「换 TV 库」和「自研鼠标层」。二选一。
